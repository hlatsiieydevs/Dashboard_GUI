# Changelog - April 2, 2026

## Features & Additions
- **"In the next few days" Widget**: Added a new calendar component displaying upcoming events for the next 7-day period.
- **South African Holidays Integration**: The upcoming calendar automatically fetches and merges South African Public holidays into the schedule, styled with an amber/gold accent border.
- **Auto-Scrolling Physics**: Implemented a smooth, custom `requestAnimationFrame` vertical auto-scrolling loop to the upcoming calendar if events overflow the widget container. Also added a `.mask-edges-vertical` CSS class for top/bottom edge fading.
- **Dynamic System Health Widget**: Upgraded the static system widget to dynamically poll the actual underlying host system details. It now queries a new `/api/system` backend endpoint using the Node.js `os` module to display the real CPU model string and track active memory usage (switching to "High Load" if memory utilization eclipses 90%).

## Fixes & Improvements
- **Resolved Calendar `fetch failed` Bug**: Fixed the calendar API rejecting fetches in Docker environments due to IPv6 routing issues. Replaced native Node 18 `fetch` calls deep inside `node-ical` with `axios` and enforced IPv4 resolution (`dns.setDefaultResultOrder('ipv4first')`).
- **Timezone Synchronization**: Migrated timezones out of `docker-compose.yml` static assignments and injected them globally via `.env` (`TZ=Africa/Johannesburg`) to prevent "today" boundary mismatches caused by Docker defaulting to UTC.
- **"Today's Schedule" Redesign**: Renamed the "Agenda" widget to "Today's Schedule", refined formatting to properly show event duration (`start - end` times natively parsed from iCal feeds), and updated container sizing to retain strict `aspect-square` proportions.
- **Correct Precipitation Modeling**: Fixed a bug where the rain probability gauge only read the closest upcoming 3-hour block. It now accurately calculates the maximum probability of precipitation (`pop`) rolling across the entire upcoming 24-hour forecast array.
